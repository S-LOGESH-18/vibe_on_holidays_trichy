# Vibe on Holidays

A responsive React + Vite travel website concept inspired by the uploaded travel poster and the Andaman Shells package browsing experience.

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Features

- Responsive tropical hero and glass-inspired travel search
- Destinations with search, type and budget filters
- Package cards, package detail pages and expandable itinerary
- Destination details and attractions
- Booking form with validation and local demo confirmation
- Favorites toggles, newsletter validation, contact demo form
- React Router navigation and responsive mobile menu
- Reduced-motion support

## Notes

This is a frontend demo. Booking requests, newsletter subscriptions and contact messages are not sent to a backend. Package prices and sample testimonials are illustrative. Remote Unsplash images require internet access.

## Stack

React, JSX, Vite, React Router DOM, Lucide React, CSS.
